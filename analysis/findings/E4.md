## Out of scope, noticed
- `~scope:default (excluded Field, Variant, Param; pass \`kinds\` to include them)` prints on every default-scope search, so a one-row response pays roughly a quarter of its length on scope prose.
- `SemanticSearchResult`/`semantic_format.rs` is still fully wired at result_format.rs:730-792, but server.rs:24 records `search_symbols` + `semantic_search` as merged into `search` — only the merged renderer is tool-reachable, and it is the one without the 1,200-char clip.
- `SearchResult::to_markdown`'s doc comment (result_format.rs:36-57) argues against a table on escaping grounds and asserts the table chrome "never paid for itself at any row count" — a prior measurement cited without a number.
- `refs` rows use the same shape (`{identity}\n  {signature}\n  {path}`, result_format.rs:183), so a row-terseness switch would naturally cover both tools.
- `HitRow::score` is carried through the whole pipeline and never rendered, so an agent cannot see a relevance number to threshold on.
